  • The left side only calls the compiled MoonBit module (moon_excalidraw.js). The official package is loaded separately and only draws the right side.

  • Both sides are asked for SVG without embedded fonts, because the official export inlines fonts as base64, which this library does not copy. Text in the previews uses your browser's fallback font.
    • 
    
  • Both sides measure text with the same fixed width (7 px per character, the metric the test suite uses). It only matters for frame titles, the one thing the export measures itself.
    • 
    
  • Everything runs in your browser. Files you choose are not uploaded.
